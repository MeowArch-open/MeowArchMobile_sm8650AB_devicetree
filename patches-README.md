# Patch notes

The patch files are stored under each owning subsystem:

- `display/patches/`
- `touch/patches/`
- `audio/patches/`
- `modem/patches/`

All kernel patches use clean Linux commit
`02294ae005b9604138a353fdf9e642b7e8d161ab` as their baseline. Newly added
kernel source is stored in the corresponding subsystem's `source/kernel/`.
